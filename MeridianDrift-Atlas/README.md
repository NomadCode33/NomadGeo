# MeridianDrift: GIS Scripting & Spatial Analysis
A collection of Python-based geospatial scripting projects exploring how to read, write, convert, and analyze spatial data. Working across industry-standard libraries — GeoPandas, OGR/GDAL, Shapely, Fiona, and Rasterio — these projects build a foundation in geospatial data management and vector analysis, from handling core GIS file formats to scripting spatial joins and producing choropleth maps that reveal real-world patterns in datasets like U.S. wildfire occurrences.

## Projects
- **[gis-data-types-storage-conversion](https://github.com/NomadCode33/gis-data-types-storage-conversion)** — Reading, writing, and converting between Shapefiles, GeoJSON, and GeoTIFF using GeoPandas, OGR, Rasterio, and GDAL.
- **[vector-data-scripting-analysis](https://github.com/NomadCode33/vector-data-scripting-analysis)** — Vector data scripting and spatial analysis using OGR, Shapely/Fiona, and GeoPandas, including spatial joins and wildfire choropleth mapping across two time periods.
